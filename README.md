# Cloud Computing & Virtualization Masterclass (ICC)

Interactive, high-yield examination preparation platform and architectural lecture slide deck for **Unit 2 (Virtualization & Distributed Infrastructure)** and **Unit 3 (Cloud Architecture & Multi-Tier Systems)**.

🌐 **Live GitHub Pages URL**: [https://abhishek-hardaha.github.io/ICC/](https://abhishek-hardaha.github.io/ICC/)

---

## 🚀 Features

- **Minimalist Launchpad (`index.html`)**:
  - Pure `#000000` pitch black landing screen with 4 glowing interactive pill buttons.
  - One-click seamless native full complete fullscreen mode.
- **Unit 2: Virtualization & Distributed Infrastructure**:
  - **47 Comprehensive Lecture Slides (`unit2.html`)**: Deep coverage from hardware abstraction to system levels (Popek-Goldberg virtualization requirements, binary translation, paravirtualization, Xen hypervisor, vSwitch, AWS Nitro, server consolidation).
  - **25 Sample Exam Questions & Solutions (`unit2_questions.html`)**: Distinguishable scenario prompts, 5-point model marking scheme, and easy-to-draw pen-and-paper vector architecture diagrams with zoom lightbox.
- **Unit 3: Cloud Architecture & Multi-Tier Systems**:
  - **51 Comprehensive Lecture Slides (`unit3.html`)**: Multi-tier cloud architectures, SOA, Enterprise Service Bus, parallel processing pipelines, AWS RDS Multi-AZ, AWS CDK, and serverless architectures.
  - **25 Sample Exam Questions & Solutions (`unit3_questions.html`)**: Distinguishable scenario prompts, 5-point model marking scheme, and easy-to-draw pen-and-paper vector architecture diagrams with zoom lightbox.

## 🛠️ GitHub Pages Setup

1. Go to repository **Settings** → **Pages**.
2. Under **Build and deployment** → **Source**, select **Deploy from a branch**.
3. Set the branch to `main` and folder to `/(root)`.
4. Click **Save**. The website will be live at `https://abhishek-hardaha.github.io/ICC/`.
